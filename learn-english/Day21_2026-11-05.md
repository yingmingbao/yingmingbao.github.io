### 01. machine　/məˈʃiːn/　*n. / v.*

- **中文释义**：机器；机械装置　v. 用机器制造
- **音标**：/məˈʃiːn/

- **例句**：The old machine still works after twenty years.
  - **例句翻译**：这台老机器用了二十年还能转。
- **常用短语**：(1) washing machine 洗衣机；(2) machine learning 机器学习

  - **引用翻译**：人生近看是悲剧，远看是喜剧。
