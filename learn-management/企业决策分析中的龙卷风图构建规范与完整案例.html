一句话定义：龙卷风图是把"每个因素在合理区间内单独变动时，目标指标如何摆动"画成的一组横向条形图——条形以基准值为中心向左（不利）向右（有利）展开，按总摆幅从大到小自上而下排列，因整体形似龙卷风而得名。
它回答的是企业决策中最常被问到、也最难凭直觉回答的问题：在几十个假设里，哪几个真正决定成败？龙卷风图的价值不在于精确预测，而在于把"什么最重要"从一页表格数字变成一眼可读的排序，从而把有限的管理注意力、合同谈判筹码和对冲资源，配置到真正敏感的少数因素上。

一、概念与原理

1.1 是什么：单因素敏感度分析的标准化图形

龙卷风图（Tornado Diagram，又称敏感度图、Swung Bar Chart）的本质是单因素轮动法（One-at-a-Time, OAT）的可视化：保持其他所有因素在基准值不变，每次只把一个因素从"悲观值"推到"乐观值"，记录目标指标（NPV、IRR、利润、回收期等）的两次结果；把这两个结果用一根横条形连起来，所有因素按条形总长度降序排列，就得到龙卷风图。

它的信息结构非常紧凑：条形长度 = 该因素的敏感度（在给定变动范围内能造成多大摆动）；条形是否跨越关键阈值线（如 NPV=0、目标收益率线）= 该因素能否单独改变决策结论；排列顺序 = 管理注意力的优先级。

1.2 为什么有效：三个其他图形难以替代的优势

  • 排序即结论。管理层不需要读懂模型，只需要看懂"哪根 bar 最长"，就能立刻知道该盯什么、该谈什么、该对冲什么。
  • 天然带方向。每根 bar 都有不利端与有利端，直接呈现"这个假设往坏走一步的代价"，与风险管理语言同构。
  • 制作成本极低。不需要分布假设、不需要模拟，一个财务模型加一张图就能完成，是蒙特卡洛之前性价比最高的一级筛子。

二、适用场景与边界

2.1 典型适用场景

高频场景
  • 投资项目决策：对 NPV/IRR 模型做敏感度排序，向投委会说明"这个项目的回报对什么最敏感"，是龙卷风图最经典的应用。
  • 定价与成本决策：判断价格战承受力、成本传导空间，量化"降价 5% 还能不能活"。
  • 预算与资源分配：在收入、成本、汇率、利率等多重不确定下，找出最值得投入管理精力的预算科目。
  • 合同谈判优先级：把谈判筹码分配到敏感度最高的条款上（价格调整公式、锁价、不可预见费、违约金上限）。
  • 风险沟通与汇报：向董事会、上级单位、金融机构直观展示项目风险结构。
  • 产品与研发组合：比较多个方案时，用各自的龙卷风图对比"谁的假设更脆弱"。

2.2 不适用与慎用情形

适合使用
目标指标可建模为若干连续参数的函数；因素各自有可信的变动区间；关心"哪个假设最重要"；需要在早期快速筛出重点；受众是需要快速形成判断的管理层。
不适合 / 需补充
因素间存在强互动或非线性阈值（一次只动一个会系统性低估风险，应补情景分析/蒙特卡洛）；决策变量是离散选择（应建决策树）；因素强相关（如价格与销量联动，OAT 假设失效）；只关心极端尾部概率（应看分布而非摆幅）；因素数量过少（两三根 bar 直接列表即可）。
最重要的一条边界：龙卷风图是局部敏感度分析——它衡量的是"在其他条件不变时，单独推动一个因素的边际影响"。当因素在现实中联动（降价往往换量、通胀往往同时推高成本与折现率）时，真实风险通常大于龙卷风图显示的水平。因此龙卷风图必须与情景/压力测试配对使用（本报告 8.7 节有算例演示）。

三、数据要求

3.1 数据清单

数据项要求与说明
目标函数与模型明确到唯一指标（NPV / IRR / 年均 EVA / 回收期），且有可复算的模型（Excel 表或脚本）。模型必须先在基准值上通过对账（与预算、历史项目、报价单校验）。
参数基准值每个因素一个基准值，标注单位与口径（含税/不含税、名义/实际、时点/期间）。口径不统一是常见错误源。
变动区间（悲观值/乐观值）核心数据。要求"可信且可比"：可信 = 有依据（见 3.2）；可比 = 各因素的区间应反映同等置信度的判断，否则摆幅不可直接比较，须在图中明示。
区间设定依据每个因素的区间依据要留档（历史波动率、专家判断记录、行业数据、合同条款），评审时会被追问。
分布假设（仅概率版需要）若要画概率龙卷风图，需为每个因素指定分布（正态/三角/对数正态等）及参数，并说明理由。
相关性判断明确因素间是否存在显著相关（价量、成本与通胀、汇率与利率）。强相关时 OAT 结论需降权解读，或改用相关抽样。
模拟设置（仅概率版）模拟次数 ≥ 5,000～10,000 次；固定随机种子以保证可复现；记录软件与版本。
元数据模型版本、数据来源、编制人/日期、假设清单。图注必须可回溯。

3.2 变动区间的四种设定方法

方法做法适用与注意
历史波动率取该变量过去 3～5 年的标准差或极值带（如大宗商品价格年化波动率 σ≈9%，取 ±2σ 或 ±10%）有充足历史数据的市场变量（原材料、汇率、利率）；注意结构性变化会让历史失效
专家德尔菲多轮匿名征求领域专家，取 P10/P90 分位共识无历史数据的战略变量（销量、渗透率）；要记录参与人与轮次
行业基准对标同类项目的实际偏差分布（如行业概算偏差 ±10%、达产率 70%～110%）投资额、工期、达产进度；注意选取可比项目
硬约束法以合同条款、政策上限、物理极限设定边界（最低保护价、产能上限、许可额度）有合同/监管锚点的变量；区间往往不对称，如实反映即可

3.3 口径与模型验证

  • 单位统一：全图只用一个单位（如"万元"），量级差异大的指标（利润 vs 百分比）不要混入同一张图。
  • 模型对账：基准 NPV 必须与独立估算（另一方模型、历史类似项目、供应商报价）交叉验证，误差可解释。
  • 极限值检查：把每个因素推到极值，确认模型输出方向与量级合理（不会出现负销量、负成本等荒谬中间态）。

四、构建方法：七步流程

  1. 明确决策问题与目标指标。写清楚"为哪个决策画图"：是否投资某项目、是否接受某报价、是否启动某计划。指标唯一（如 5 年期 NPV），并明确决策阈值（NPV>0 且 IRR>WACC）。
  2. 建立基准模型并对账。把所有假设固化为参数表 + 现金流表，基准情形跑通并与外部数据校验。基准值画成图中的竖直虚线——它是整张图的锚。
  3. 筛选因素并设定变动范围。从长假设清单中筛出 5～12 个关键因素（筛法：专家列举 + 初步试算 + 剔除明显二阶因素），按 3.2 的方法为每个因素设定悲观/乐观值与依据。
  4. 单因素轮动测算。严格保持"其他因素 = 基准值"，逐个因素代入悲观值、乐观值各跑一次模型，记录目标指标。建议用数据表/脚本批量执行，避免手工改参出错。
  5. 计算摆幅并排序。摆幅 = 乐观值 − 悲观值（取绝对值）。按摆幅降序排列，最大的放最上面。同时计算两个派生指标：单位敏感度（每变动 1% 对指标的影响）和弹性系数（指标变动% ÷ 参数变动%），用于跨因素可比性修正。
  6. 选择制式并成图。绝对值制（X 轴 = 指标值）适合决策评审；偏离量制（X 轴 = 相对基准的偏离）适合内部分析。按第五至七章的规范设置坐标轴、排序、标注、配色。
  7. 解读并转化为行动。回答四个问题：谁最敏感？谁能单独翻转结论？缓冲空间多大？因素间是否联动？把结论翻译成监控 KPI、合同条款、对冲手段或分期投资的期权设计（见第九章）。

五、坐标轴与置信区间设置

5.1 坐标轴：两种制式

制式X 轴含义与画法优点适用场合
绝对值制X 轴 = 目标指标值（如 NPV，万元）。每根 bar 从悲观值延伸到乐观值，基准值为竖直虚线直接看出基准位置、bar 是否跨越盈亏线（NPV=0），决策者无需心算换算对外汇报、投委会评审、需要判断"会不会亏"的场合
偏离量制X 轴 = 相对基准的偏离量（ΔNPV）。bar 中心在 0，左负右正强调各因素"贡献了多少摆动"，跨因素可比性强；适合基准值很大、关注相对影响时内部分析、因素很多时的排序比较

坐标轴设置要点

  • 单位入轴：轴标题必须带单位（"项目净现值 NPV（万元）"）；图题带指标名与基准值。
  • nice 刻度：刻度取整齐数字（每 500 万元一格），刻度数 5～9 个，太多则密、太少则粗。
  • 务必包含负值区：若指标可能为负（如 NPV），X 轴下限要留出负值空间，否则 bar 会被截断、跨越阈值的视觉信息丢失。
  • 两条基准线：竖直虚线标基准值；若存在决策阈值（NPV=0、目标收益率），用另一条略粗的实线标出，可加浅色底纹区分"可行区/不可行区"。
  • 类别轴（Y 轴）：只有因素名称，按摆幅降序；禁用双 Y 轴，不要把不同指标塞进一张龙卷风图。

5.2 置信区间设置

这是最容易被含糊处理的一环。龙卷风图的"区间"有两种完全不同的性质，混用会导致严重的解读错误。

类型条形端点含义推荐区间使用条件与要点
确定性情景区间悲观/乐观情形下的指标点估计值，是"if-then"结果，不是统计置信区间不适用（点估计）单因素 OAT 的默认形态。必须在图注写明"条形为情形值，非置信区间"，避免被误读
概率型区间（蒙特卡洛龙卷风图）该因素单独抽样（其他因素按设定处理）时，目标指标分布的 P10 / P90 端点，P50 为中心P10–P90（80% 区间）为主流；更保守可用 P5–P95（90%）需要分布假设、≥1 万次模拟、固定随机种子；条形长度 = 敏感度，条形"厚度/宽度" = 该因素的不确定性，二者相乘近似风险贡献
估计不确定性误差棒摆幅本身的抽样误差（参数由样本估计时）±1.96×标准误当参数来自回归/实测样本（如价格弹性估计值 ±SE），在 bar 端加误差棒，体现"连敏感度本身都没测准"
关键规则
  • 不要用 min/max 做概率端点：极值随模拟次数剧烈漂移，不可复现也不稳定，应使用分位数。
  • 不要混图：确定性情形 bar 与概率分位 bar 不要画在同一张图、同一坐标轴上。
  • 区间不可外推：概率龙卷风图展示的是"单个因素在其设定分布内变动时"的条件区间，不是项目总回报的总体分布——后者要看直方图/CDF，两者数值不可互相引用。
  • 明示分位定义：图注写明"P10–P90，基于 10,000 次蒙特卡洛模拟，随机种子 20261016"。

六、正负因素排序与标注规范

6.1 排序规则

  • 主排序（默认）：按总摆幅（|乐观 − 悲观|）降序，最长的 bar 置于最上方——视觉动线自然从最重要到最次要。
  • 下行视角（可选）：若决策核心是"最坏会怎样"（如债务契约、保本经营），改按不利端摆幅降序，并在图注说明排序口径。
  • 剔除与归并：摆幅小于决策阈值（如引起的 NPV 变动 < 基准值的 2%）的因素可剔除或合并为"其他"，在图注说明，保持 5～12 根的清爽规模。
  • 并列与同族因素：摆幅接近时按业务重要性打破平局；同一因素的多个子项（如成本的料工费）可用缩进表示层级。
  • 方向一致性：每根 bar 的不利端在左、有利端在右；若某因素只有单侧影响（如补贴退坡只可能变差），bar 只画一侧，如实呈现。

6.2 标注规范清单

标注对象规范
因素名称三要素齐全：参数业务名 + 基准值与单位 + 变动范围。例："产品单价（基准 120 元/件，±8%）"。只写"价格"不给基准与幅度是常见缺陷
条形端点值两端标注该情形下的指标值，与坐标轴同单位、同精度；千分位分隔；数字用等宽字体（tabular figures）保证对齐
基准线与阈值线基准值竖直虚线（标注"基准 800"）；决策阈值线（NPV=0）略粗实线（标注"NPV=0 / 盈亏平衡"）；可行/不可行区可加浅色底纹
阈值穿越警示bar 跨越盈亏线时（该因素可单独翻转结论），端点值可用强调色或加"⚠ 由盈转亏"标记——这是全图信息密度最高的信号
颜色图例说明正负端配色含义（见 7.1），置于图的上沿或右侧，不与条形重叠
图题三要素：指标 + 单位 + 方法。例："项目 NPV 龙卷风图（万元）：单因素敏感度，其余因素固定"
脚注模型版本、变动范围依据摘要、数据来源、编制日期；概率版加模拟次数与随机种子
摆幅与弹性（可选）条端或右侧附小字"摆幅 2,184"，或另附弹性系数表，弥补"变动范围不同导致摆幅不可直接比"的缺陷

七、图表样式与可读性优化要点

7.1 配色：正负端的方向约定

龙卷风图的左右两段必须用可辨识的双色区分。约定有两种，在中国财务语境下默认使用前者：

配色方案不利端（左）有利端（右）说明
中国财务惯例（默认）绿 = 不利 / 减值 / 下行红 = 有利 / 增值 / 上行与 A 股"涨红跌绿"一致，符合国内管理层直觉；面向欧美受众时需切换并在图注说明
国际惯例（备用）红 = 不利 / 风险绿 = 有利 / 改善西方财务报表常用；跨国汇报时与受众对齐
单色方案同一色系深浅两档（深 = 不利，浅 = 有利）黑白打印、色盲友好场景；需靠图例明确方向
注意：配色方向一旦选定，全图、全报告必须一致；跨文化汇报时在图注注明"本图采用中国财务配色惯例（红=有利，绿=不利）"，避免误读。

7.2 版式与可读性

  • 横向条形：因素名长、数值范围大，横向布局保证名称完整可读；bar 高度约为行距的 50%～55%，留足呼吸感。
  • 左对齐名称区：因素名统一右对齐至绘图区左缘，形成整齐的视觉边缘；名称与数值之间留 ≥10px 间距。
  • 网格线浅而后撤：浅色虚线置于条形下层，仅保留刻度参考功能，不与数据争夺注意力。
  • 强调线只留两条：基准线（虚线）+ 阈值线（实线）加粗，其余线条一律弱化。
  • 数字等宽、右端对齐：端点值用等宽数字字体；同一图内小数位数一致。
  • 字号与对比度：正文 ≥10.5pt，文字与背景对比度 ≥4.5:1；投屏场景主字号再放大一档。
  • 禁项：3D 效果、渐变填充、阴影、圆角过度装饰、双坐标轴、截断轴（bar 不得被 X 轴边界切断）。
  • 打印友好：白底、避免大面积深色填充；先转灰度检查可读性。

7.3 规模控制

  • 单图因素数 5～12 个：少于 5 个不如直接列表；多于 12 个则视觉噪音超过信息量，应归并或分层。
  • 一行一个因素，行高一致；相关因素（如成本族）相邻放置，可用缩进体现层级。

7.4 反面模式清单

不要这样做
  • 各因素变动幅度随意设定（有的 ±5%、有的 ±30%）却直接比较摆幅，且不在图注说明；
  • 把"悲观/乐观情形值"说成"80% 置信区间"；
  • 因素名只有"收入""成本"这种词，无基准值、无单位、无幅度；
  • X 轴从 0 起而所有 bar 都在高位，摆幅差异被视觉压缩；
  • 图题只写"敏感度分析"，无指标、无单位、无方法；
  • 用 min/max 当概率端点；图注不写模拟次数与种子；
  • 一张图里又画 NPV 又画 IRR；
  • 忽略因素相关性提示（价量联动时不加任何说明）。

八、完整案例：从数据准备到成图

8.1 决策问题

某制造企业拟投资 6,000 万元新建一条智能装配产线，运营期 5 年。基准测算 NPV ≈ 800 万元、IRR ≈ 14.7%，高于 10% 的 WACC，项目可行。决策层需要回答：这个结论对哪些假设最敏感？哪些假设单独恶化就能让项目由盈转亏？为此构建单因素龙卷风图。

8.6 结果解读：敏感度排序与盈亏平衡阈值

排序结论：单价（摆幅 2,184）＞销量（1,319）＞初始投资（973）＞原材料（773）＞折现率（746）＞固定成本（409）。前两个因素均为收入侧因素——这个项目的风险结构是"市场风险主导"而非"成本风险主导"。若按弹性系数排序，折现率升至第二（22.3/pp），但其合理变动范围窄（±2pp），实际优先级仍低于收入侧因素——这正是"摆幅看实际影响、弹性看单位效率、两者结合看优先级"的用法。

盈亏平衡阈值：把每个因素单独推到 NPV=0，得到各因素的"安全边际"：

8.7 联动与压力测试：为什么龙卷风图只是起点

现实中价格与销量往往正相关（降价换量）。把两个因素按联动情景同时变动，结果显著超出单因素分析的线性叠加预期：

关键教训：单因素龙卷风图显示"销量有 12% 缓冲"，容易让人高估安全性。但价格 −5% 同时销量 −5%（各自都在合理波动范围内）就使 NPV 转负——相关因素的联合冲击远大于单因素摆幅之和。龙卷风图必须配合：①价量联合情景表；②概率型龙卷风图（P10–P90）；③敏感性监控 KPI，三者共同构成完整的风险图景。

九、如何据此判断敏感度与决策风险

从龙卷风图到决策结论，建议按以下六步框架推进：

  1. 看排序定主次。前 2～3 根最长的 bar 就是项目的主要风险源。若头部因素集中于收入侧，项目是市场风险型；集中于成本/投资侧，则是执行风险型——两类风险的管理手段完全不同。
  2. 看穿越定生死。凡是 bar 跨越盈亏平衡线（或目标收益率线）的因素，具备"单独翻转决策结论"的能力，属于关键敏感因素，必须进入投委会重点审议与合同条款设计。
  3. 看弹性做校正。当各因素变动幅度不同时，用弹性系数（每 1% 参数变动引起指标变动百分之几）做跨因素可比性修正，避免"范围定得宽所以摆幅大"的伪排序。
  4. 看缓冲定容错。计算每个因素的盈亏平衡安全边际（图 2）。缓冲 <10% 的因素几乎没有试错空间，应设置预警线和熔断机制；缓冲 >40% 的因素可放心纳入常规监控。
  5. 看联动防低估。识别相关因素对（价量、成本—通胀、汇率—利率），做联合情景与压力测试；龙卷风图给出的排序在强相关场景下需要整体上调风险等级。
  6. 转行动闭环。把每个头部因素转化为具体动作：监控指标与频率、合同条款（锁价/价格调整公式/不可预见费/违约金）、对冲工具（套保、双供应商、战略库存）、或保留期权（分期投资、小规模试点）。
风险等级判据（满足其一）管理动作
高敏感 / 关键弹性 ≥10；或缓冲 <10%；或 bar 穿越盈亏线每周监控；写入投委会决议要点；合同硬条款（锁价、调整公式）；设置预警熔断线
中敏感弹性 4～10；或缓冲 10%～25%月度监控；预算中设专项缓冲；对冲/备选方案（套保、双供应商、备选产能）
低敏感弹性 <4 且缓冲 >25%季度例行监控；常规管控即可，不占用谈判与管理资源

落到本案例：产品单价 = 高敏感关键因素（弹性 17.1、缓冲 5.9%、唯一穿越盈亏线）→ 定价策略、长协锁价与价格调整公式、竞品价格监控、上市前价格测试；年销量与初始投资 = 中敏感（缓冲 12.1% / 16.4%）→ 渠道进度月度复盘、EPC 固定总价 + ≥10% 不可预见费 + 变更控制；原材料 = 中敏感（缓冲 20.7%）→ 套期保值、战略备库、双供应商、采购价格联动条款；折现率与固定成本 = 低敏感（缓冲 47.4% / 58.6%）→ 例行监控，无需专项资源。

十、常见错误与质量检查清单

10.1 十个高频错误

  1. 各因素变动范围设定随意且不一致，摆幅排序失去可比性；
  2. 把确定性"悲观/乐观情形值"误称为"置信区间"；
  3. 因素命名缺基准值、单位或幅度，读者无法复算；
  4. X 轴截断（从 0 起而数据全在高位），压缩视觉差异或丢失亏损区；
  5. 一张图混用多个指标（NPV + IRR），或使用双坐标轴；
  6. 忽略因素相关性提示，读者按"因素独立"误读；
  7. 因素超过 12 个或少于 5 个，图形信噪比失衡；
  8. 图题与脚注缺失（无指标、无单位、无方法、无来源、无日期）；
  9. 概率版用 min/max 作端点、不写模拟次数与随机种子；
  10. 只出图不给行动——龙卷风图止步于"看"，没有转化为监控、条款与对冲。

10.2 成图前检查清单

  • 基准模型已通过对账，基准值线位置正确；
  • 每个因素的变动范围有书面依据，且各范围置信度相当；
  • OAT 严格执行：每次只改一个因素，无手工改参遗漏；
  • 摆幅、排序、弹性三项计算经第二人复核；
  • 坐标轴含负值区、刻度整齐、单位入题、无双轴；
  • 因素名三要素齐全，端点值标注完整、精度一致；
  • 正负端配色符合受众惯例且全报告一致，图例清晰；
  • bar 穿越阈值处有警示标记；
  • 图题含"指标 + 单位 + 方法"，脚注含模型版本/来源/日期（概率版含模拟次数与种子）；
  • 已配套联合情景/压力测试说明，并已生成行动清单。

附录 A：Excel 操作步骤（确定性龙卷风图）

  1. 建参数表：B 列放基准值（销量、单价、成本、投资、税率、WACC），每行一个参数并备注单位。
  2. 建现金流计算区：公式全部引用参数表单元格，禁止硬编码数字。
  3. NPV 单元格：=NPV(WACC, OCF1:OCF5) + 残值/(1+WACC)^5 - I0。
  4. 批量测算：用"数据 → 模拟分析 → 模拟运算表（数据表）"，行引用因素列、列引用 NPV 单元格；或复制模型 6×2 份，每份只改一个参数。
  5. 整理结果表：因素名 / 悲观 NPV / 乐观 NPV / 摆幅（=乐观−悲观）/ 排序。
  6. 做辅助列：段1 = MIN(悲观, 基准) − X轴下限；段2 = |悲观 − 基准|；段3 = |乐观 − 基准|。
  7. 插入堆积条形图：三个系列堆积；段1 设为"无填充"；类别轴勾选"逆序类别"使摆幅最大的因素显示在最上方；X 轴最小值设为 −1,000（固定，避免自动缩放截断）。
  8. 加基准线：插入竖直误差线/散点系列画基准值与零线，或叠加一个透明系列的误差线实现。
  9. 标注：添加数据标签（段2、段3 端点值）、图例改为中文正负端说明、补齐图题与脚注。

附录 B：Python 核心代码（计算 + 绘图）

# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.family"] = "Microsoft YaHei"

def npv(I0=6000.0, life=5, salvage=1000.0, Q=40.0, P=120.0,
        vc_unit=62.0, fixed=480.0, tax=0.25, r=0.10):
    """智能装配产线 NPV 模型（单位：万元）"""
    R, VC = Q * P, Q * vc_unit
    dep = (I0 - salvage) / life
    ocf = (R - VC - fixed - dep) * (1 - tax) + dep
    af = (1 - (1 + r) ** -life) / r
    return -I0 + ocf * af + salvage * (1 + r) ** -life

base = npv()
scen = [  # (因素, 悲观 kwargs, 乐观 kwargs)
    ("产品单价",     dict(P=110.4),  dict(P=129.6)),
    ("年销量",       dict(Q=36.0),   dict(Q=44.0)),
    ("初始投资",     dict(I0=6600.), dict(I0=5400.)),
    ("原材料成本",   dict(vc_unit=65.4), dict(vc_unit=58.6)),
    ("折现率",       dict(r=0.12),   dict(r=0.08)),
    ("固定运营成本", dict(fixed=552.),dict(fixed=408.)),
]
low  = [npv(**lo) for _, lo, _ in scen]
high = [npv(**hi) for _, _, hi in scen]

order = np.argsort([h - l for l, h in zip(low, high)])[::-1]  # 按摆幅降序
fig, ax = plt.subplots(figsize=(9, 4.6))
for i, k in enumerate(order):
    ax.barh(i, base - low[k],  left=low[k], color="#4B7D5B", height=.55)  # 不利端（绿）
    ax.barh(i, high[k] - base, left=base,   color="#A8544A", height=.55)  # 有利端（红）
    ax.text(low[k] - 40,  i, f"{low[k]:,.0f}",  ha="right", va="center", fontsize=9)
    ax.text(high[k] + 40, i, f"{high[k]:,.0f}", ha="left",  va="center", fontsize=9)
ax.axvline(0,    color="#A8544A", lw=1.4)            # 盈亏平衡线
ax.axvline(base, color="#1F2328", lw=1.4, ls="--")   # 基准线
ax.set_yticks(range(len(order)))
ax.set_yticklabels([scen[k][0] for k in order])
ax.set_xlabel("项目净现值 NPV（万元）"); ax.set_xlim(-1000, 3000)
ax.invert_yaxis()                                    # 摆幅最大者置顶
ax.spines[["top", "right"]].set_visible(False)
plt.tight_layout(); plt.savefig("tornado.png", dpi=200)
